# The NOUS Manifesto

1. Writing code used to be the same act as understanding it. Generation severed them.
2. A passing test proves behavior someone imagined. Only a human can answer the rest.
3. Understanding is not a feeling. It is a claim — specific, signed, and checkable.
4. Understanding is perishable. Change the code and the proof must die with it.
5. What nobody understands, nobody owns. What nobody owns should not ship.
